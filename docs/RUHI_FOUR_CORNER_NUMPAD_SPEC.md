# 如喜 (RuhI) 智慧型四角號碼輸入法（4×5 九宮格小鍵盤專責 × 主鍵盤直出英數）架構與使用規範

## 一、設計緣起與核心定位

傳統形碼輸入法（如倉頡、大易、行列）雖具備低重碼率優勢，但往往需要記憶散佈於標準 QWERTY 主鍵盤 26~30 個鍵位上的數百個字根，且必須雙手大幅移動擊鍵。

**「如喜智慧型四角號碼輸入法（Four-Corner Smart IME）」** 奠基於王雲五先生於 1925 年發明的「四角號碼檢字法」，將漢字結構抽象為 `0` 至 `9` 共十種基本筆形，並結合如喜（RuhI）核心的現代漢語語料庫、二元語境轉移引擎（`TransitionEngine`）與 **「`-` 詞前導多字詞簡碼矩陣（Word-Prefixed Phrase Shortcode Matrix）」**，使單手操作 **4×5 實體九宮格小鍵盤**（含 104 標準鍵盤右側九宮格區與外接獨立 18/19 鍵九宮格小鍵盤）即可完成單字、現代雙字詞、三字詞、四字成語與全形標點的流暢輸入；同時讓**主鍵盤區保持免切換直出一般英數字與符號**。

## 二、筆形編碼定義與現代化記憶口訣

### 1. 胡適原版與現代化白話口訣
> **胡適口訣：「橫一垂二三點捺，叉四插五方塊六，七角八八九是小，點下有橫變零頭。」**  
> **現代口訣：「一橫二垂三點捺，點下帶橫變零頭；叉四插五方塊六，七角八八小是九。」**

### 2. 0~9 筆形分類與取碼參考表

| 號碼 | 筆形類別 | 包含筆畫與字根特徵 | 範例字／部件（括號內為該角部位） |
| :---: | :---: | :--- | :--- |
| **`0`** | **頭**（兼容撇／左鉤） | `亠`（一點一橫之言字頭、主字頭、广字頭）；初學寬容模式同步支援單筆撇與左鉤 | 言(上)、主(上)、廣(上)、症(上) |
| **`1`** | **橫** | `一`（橫）、`乚`（挑／提、右鉤） | 天(上)、土(下)、地(左下)、江(左下)、元(右下) |
| **`2`** | **垂** | `丨`（豎）、`丿`（撇）、`亅`（左豎鉤） | 千(上)、順(左)、山(左下)、則(右下)、月(左下) |

| **`9`** | **小** | `小`、`忄`、`⺌`（中豎帶左右兩點之小字形） | 小、尖(上)、慕(下)、榮(下)、惟(左) |

### 3. 取碼順序與「三軌寬容機制」
- **標準取碼順序**：依序取漢字之 **「左上角① ➔ 右上角② ➔ 左下角③ ➔ 右下角④」** 共 4 碼（支援第 5 碼「附角⑤」精確消歧）。
- **三軌相容容錯編譯（總計 76,299 筆條目）**：
  1. **Unicode Unihan 官方標準碼 (`full`)**：100% 涵蓋 `Unihan_DictionaryLikeData.txt` 之 `kFourCornerCode`（共 17,491 個單字）。
  2. **台灣正體／異體字雙向對等共享 (`variant`)**：如 `台` (`2360.0`) 與 `臺` (`4010.4`)、`裡` ⇄ `裏`、`線` ⇄ `綫`、`為` ⇄ `爲`、`真` ⇄ `眞` 雙向互通，無論使用者依何種正異體字形拆碼皆能同時命中。
  3. **初學者直覺拆碼寬容 (`fuzzy`)**：解除王雲五原版「同一筆畫已用過須補 `0`」之記憶門檻（例如將 `台` 下方之 `口` 直覺拆為雙 `6` 輸入 `2366`、將 `天` 輸入 `1183`、將 `才` 輸入 `1222`），並內建鄰近筆畫動態模糊救援（如 `1↔7`、`4↔5`、`8↔9`、`0↔2`）。

## 三、核心演算法創新：「單字 `XXXX`」與「`-` 詞前導 `-XXXX / -XXXXX / -XXXXXX`」零碰撞分流架構

為徹底解決傳統四角號碼「二字詞 4 碼與單字 4 碼混在同一候選清單互相擠佔」之結構問題，本引擎採用 **「`-` 詞彙前導分流」** 與 **「階層式混合多字詞構詞法」**：

1. **一般單字模式（不按 `-`，直接輸入 `XXXX` 或 `XXXXX`）**：
   - 候選清單 **100% 純單字優先**，高頻單字如 `天 (1080)`、`才 (4020)`、`大 (4003)`、`一 (1000)` 永遠穩居單字首選，絕不被二字詞干擾。
2. **`-` 詞彙前導模式（先按小鍵盤 `-` 再打碼，共收錄 34,305 組常用詞彙）**：
   - **二字詞（`-` + `首(1,2) + 尾(1,2)` = `-XXXX`）**：取首字前兩角（左上①＋右上②）＋尾字前兩角（左上①＋右上②）：
     - **「台灣 / 臺灣」**：`-` + `台(23)` + `灣(32)` ➔ 輸入 **`-2332`** 或 **`-4032`** 直接首選「台灣」！
     - **「天才」**：`-` + `天(10)` + `才(40)` ➔ 輸入 **`-1040`** 直接首選「天才」（與單字 `1040`「干/平/于」徹底分流）！
     - **「主權」**：`-` + `主(00)` + `權(44)` ➔ 輸入 **`-0044`** 直接首選「主權」！
     - **「電腦」**：`-` + `電(10)` + `腦(72)` ➔ 輸入 **`-1072`** 直接首選「電腦」！
   - **三字詞（`-` + `首(1,3) + 中(1) + 尾(2,4)` = `-XXXXX`）**：首字取左半邊（左上①、左下③），中間字取左上①，尾字取右半邊（右上②、右下④），左包右收、首選免選字率達 **90.9%**：
     - **「輸入法」**：`輸(5802)` 取 `1,3`=`50` ＋ `入(8000)` 取 `1`=`8` ＋ `法(3413)` 取 `2,4`=`43` ➔ 輸入 **`-50843`** 唯一命中「輸入法」！
     - **「台灣人」**：`台(2360)` 取 `1,3`=`26` ＋ `灣(3212)` 取 `1`=`3` ＋ `人(8000)` 取 `2,4`=`00` ➔ 輸入 **`-26300`** 直接命中「台灣人」！
     - **「為什麼」**：`為(3402)` 取 `1,3`=`30` ＋ `什(2420)` 取 `1`=`2` ＋ `麼(0023)` 取 `2,4`=`03` ➔ 輸入 **`-30203`** 直接命中「為什麼」！
   - **四字成語／詞彙（`-` + `首(1,3) + 中一(1) + 中二(1) + 尾(2,4)` = `-XXXXXX`）**：首選唯一率達 **98.9%**：
     - **「四角號碼」**：`四(6021)` 取 `1,3`=`62` ＋ `角(2722)` 取 `1`=`2` ＋ `號(6121)` 取 `1`=`6` ＋ `碼(1162)` 取 `2,4`=`12` ➔ 輸入 **`-622612`** 唯一命中「四角號碼」！
     - **「一舉兩得」**：`一(1000)` 取 `1,3`=`10` ＋ `舉(7750)` 取 `1`=`7` ＋ `兩(1022)` 取 `1`=`1` ＋ `得(2624)` 取 `2,4`=`64` ➔ 輸入 **`-107164`** 唯一命中「一舉兩得」！

## 四、104 鍵盤與 18/19 鍵外接九宮格人體工學配置

### 1. 九宮格小鍵盤按鍵配置（預設全盲打閉環模式 `"blind_closed_loop"`）
右手全程無須離開數字小鍵盤，即可完成單字與詞彙輸入、選單快選、上下翻頁、萬用字元查詢與全形標點輸入：

| 小鍵盤按鍵 | Windows VK | 功能定位 | 行為說明 |
| :---: | :---: | :---: | :--- |
| **`NumLock`** | `0x90` | **原生數字鎖** | 保留硬體原生 `NumLock` 功能（適用 104 鍵盤與外接 18/19 鍵獨立九宮格；18/19 鍵外接鍵盤自帶實體 `Backspace` 鍵） |
| **`0` ~ `9`** | `0x60..=0x69` | **四角取碼／選單快選** | 一般狀態下輸入四角編碼；於 `/` 字詞選單或 `.` 標點選單狀態下，按 `1`~`0` 直接快選第 1~10 項 |
| **`/` (Divide)** | `0x6F` | **字詞選單** | 進入字詞選單模式（預設高亮第 2 項）：按 `1`~`0` 數字鍵快選，按 **`+` 翻下一頁**，按 **`-` 翻上一頁**；若剛按過 `+` 收攏字詞至輸入座，按 `/` 可直接開啟游標前字詞之重選清單 |
| **`*` (Multiply)** | `0x6A` | **萬用字元 (`*`)** | 不確定某角號碼時以 `*` 代替任意筆形（如輸入 `23*0` 可匹配 `2360`「台」） |
| **`.` (Decimal)** | `0x6E` | **標點符號選單前導** | 展開 30 種常用中文全形標點選單（第 1 頁 `.1`=`，`、`.2`=`。`、`.3`=`、`、`.4`=`？`、`.5`=`！`、`.6`=`：`、`.7`=`；`、`.8`=`「」`、`.9`=`（）`、`.0`=`……`，按 `+`/`-` 翻至第 2、3 頁括號與特殊符號）；**連按兩下 `..` 直接輸出全形逗號「，」** |
| **`-` (Subtract)** | `0x6D` | **「詞」前導／翻上一頁** | 一般狀態下開啟 **`➖詞` 詞彙前導模式**（亦支援打完一字後直接按 `-` 自動收攏前字並無縫接打下一詞）；在 `/` 或 `.` 選單中作為 **翻上一頁 (PageUp)** |
| **`+` (Add)** | `0x6B` | **字、詞分隔／翻下一頁** | 一般狀態下將當前首選字／詞收攏進入「如喜輸入座組句區」（不立即上屏）；在 `/` 或 `.` 選單中作為 **翻下一頁 (PageDown)** |
| **`Enter`** | `0x0D` | **整句完稿送出** | 確認當前未上座之四角碼，並將「如喜輸入座」內的整串句子一次送出至目標應用程式視窗 |

### 2. 104 鍵盤「九宮格編碼 × 主鍵盤直出英數」雙區平行免切換架構
在智慧四角模式下，系統於 Windows TSF 底層自動區分**九宮格小鍵盤 (`0x60..=0x6F`)** 與**主鍵盤區 (`0x41..=0x5A`, `0x30..=0x39`, `VK_OEM_*`)**：
1. **平時無組字緩衝時（`!has_buffer`）**：主鍵盤上的英文字母 `A`~`Z`、上方橫排數字 `0`~`9` 與主鍵盤半形符號（`-`、`=`、`[`、`]`、`;`、`'`、`,`、`.`、`/` 等）**100% 直接放行直通目標視窗**，使用者左手在主鍵盤打英文、數字、程式碼或網址時，完全不必按 `Shift` 或 `CapsLock` 切換輸入模式！
2. **正在輸入座組句時（`has_buffer`）**：若使用者正以九宮格組句（例如按 `-2332` 打出「台灣」），中途直接在主鍵盤敲擊 `2026` 或 `AI`，系統會**自動將九宮格未決字詞收攏入座，並無縫在句中接上 `2026` 或 `AI`**，最後按 `Enter` 即可整句送出 `"台灣2026"`！
