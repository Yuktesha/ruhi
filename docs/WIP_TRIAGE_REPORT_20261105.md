## 4. 手動驗證清單（Agent 不啟動 GUI）

請先執行 `hot_reload.ps1` 載入新建置之 `ruhi_tsf.dll`，再於 Notepad++、Chrome 表單、LINE 中逐項確認：

1. `Shift + Space` 切換「半／全」：全形模式下英數輸出為 `ＳＩ`、`１２３`，標點為全形。
2. 半形模式下，數字後接 `%`、`+`、`:` 輸出半形（`1%`、`3+3`、`12:30`）；中文後接 `,` 輸出 `，`。
3. `Ctrl + `` ` ``、`Ctrl + ~` 輸出 `～`；`tilde_toggle_mode = "punct"` 時單按 `~` 輸出 `～`。
4. 打「一試再試」後按 `↓`，候選前段應有「一事再事」等諧音組合，選取後整組四字替換。
5. 輸入門牌地址（如「基隆市中正區和憲里1鄰和一路13號」），候選列應出現帶 3+3 郵遞區號之格式。
6. 許氏模式單按 `k` 再按聲調鍵，可打出零聲母「ㄤ」音節（如「昂」）。
7. 英文混打不受影響：`this is a small book`、`and `、`hi ` 直接送出英文。
8. 新規則：「額度剩1%」、「分數勝1%」、「寫下新對話」、「待額度恢復後執行」。
