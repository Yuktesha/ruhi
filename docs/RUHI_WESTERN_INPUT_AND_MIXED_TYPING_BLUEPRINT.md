## 📌 緣起與痛點本質剖析 (Root Cause Analysis)

在追求「許氏鍵盤＋歐文混打」的歷程中，早期版本曾嘗試採用「盲目排除法（Negative Fallback）」，即：
> 「當組字緩衝區湊不出合法注音、或查無注音字時，倒退回西文詞庫嘗試匹配。」

### 盲目排除法的致命缺陷
1. **負向防守不是語言理解**：
   - 演算法並不知道什麼是「合理的英文」，只是被動地猜測「這看起來不像注音」。
2. **語意劫掠與詞庫撞車**：
   - **`fyen` 劫掠事件**：許氏注音中「發」為 `f`（ㄈㄚ），「音」為 `yen`（ㄧㄣ）。因打字停頓或一聲空格結算，引擎看到前半段尚未形成多字詞，便轉向外語辭庫，將其當成丹麥島嶼地名 `fyen` 送出。
   - **`is` / `as` 撞車事件**：許氏鍵盤中 `is`（ㄞ˙）與 `as`（ㄘ˙）在國語中無合法漢字，但寬鬆的聲調容錯回退機制（Tone fallback）強制回退至高頻漢字「愛」與「此」，破壞了正常的英文單字輸入。
3. **結論**：
   - **現階段的盲目排除法屬於便宜行事，無法成就「許氏鍵盤+歐文混打」目標。**
   - 真正的混打實現條件：**「唯有當演算法可明確辨認組字為合法（或接近合法）歐文時」**，方可進行混打仲裁。

## 🎯 現階段產品規格定案 (Specification Baseline)

1. **大千鍵盤（41 鍵）**：
   - 納入「注音＋歐文混打」主力研發與實作平台，利用大千佈局的語音學結構合法性規則，打造無切換智慧體驗。
2. **許氏鍵盤（26 鍵）與漢語拼音**：
   - **全面關閉脆弱的自動猜測混打**。
   - 恪守「確定性（Determinism）」原則：以經過數十年驗證的 **Caps Lock / Shift** 模式切換為主，提供零心智負擔、不被中斷的純粹輸入節奏。

## 🏛️ 戰略核心：純歐文鍵盤輸入引擎之必要性

西文輸入在現代輸入法中，**絕不應只是「直接把 ASCII 按鍵透傳到目標視窗的旁路（Bypass）」**。
建立一個健壯、獨立的「純歐文鍵盤輸入引擎（Western Input Engine）」，是實現終極混打的**絕對先決條件**：

### 純歐文引擎核心職責
1. **正向詞庫與形態學（Morphology）**：
   - 建立高頻英文、常見詞形變化（-ing, -ed, -s）、常用前綴/後綴辭庫。
   - 具備辨識「合法/接近合法歐文單字」之信心評分模型（Confidence Scoring）。
2. **西文專業輸入行為**：
   - 空格自動分詞與標點依附規則（Punctuation spacing）。
   - 智慧大小寫（Capitalization）、駝峰命名（CamelCase）、代碼識別與防干擾模式。
   - 正確的西文引號（`'` `"`）與中文引號（`「` `」` `『` `』`）邊界隔離。

## 🔮 終極目標：雙軌正向 Trellis 晶格競爭模型

當「許氏中文引擎」與「純歐文引擎」兩者皆具備健全的正向語言學理解時，未來的混打將徹底告別「打地鼠排除法」，進化為 **雙軌正向晶格競賽（Dual-Track Trellis Lattice Competition）**：

```
                    ┌─── [中文軌] Layer 1 語法構式 + Layer 2 轉移引力 ───┐
                    │                                                     ▼
按鍵流 (Key Stream) ─┤                                               [Viterbi 最優解決策] ➔ 上屏文字
                    │                                                     ▲
                    └─── [歐文軌] 歐文字典信心度 + 詞形形態學連綴規則 ─────┘
```

$$Score_{\text{Sentence}} = \arg\max \left( Score_{\text{Chinese}}(\text{注音構式路徑}),\; Score_{\text{Western}}(\text{歐文正向信心度}) \right)$$

* **輸入 `this is a smallbook`**：歐文引擎以近乎 100% 的合法單字鏈與語法信心度正面壓倒中文晶格，自然輸出純英文，絕無劫掠。
* **輸入 `fyen` (發音)**：中文軌具備高頻雙字詞「發音」凝聚力，歐文軌僅為生僻島嶼名，中文軌毫無懸念獲勝。
