## 一、可重現評測指令與規範

所有開發集與基準延遲測試皆可直接透過 `Release` 建置二進位檔於本機重現（嚴守盲測紀律：`test.tsv` 與 `typing_tw.tsv` 僅於 `7dcdb24` 定案時執行唯一一次終檢，報告遮蔽所有測試句原文）：

```powershell
# 1. 建置核心評測與重排器二進位檔
cargo build --release --manifest-path ruhi-core\Cargo.toml --lib --bin ruhi_reranker --bin ruhi_eval --bin ruhi_ngbin --bin ruhi_lkbin

# 2. 開發集離線基準品質閘門（對照 eval_reports/dev_gate_baseline.json）
.\ruhi-core\target\release\ruhi_eval.exe --set dev --gate

# 3. 開發集 N-Best Oracle 上界（比較標準 K=32 與 Stage D2 多樣化繞道）
.\ruhi-core\target\release\ruhi_eval.exe --set dev --nbest-oracle --top-k 32
.\ruhi-core\target\release\ruhi_eval.exe --set dev --nbest-oracle --top-k 32 --diverse-nbest

# 4. 開發集（dev.tsv）RLNM0001 神經重排實測（採用預設 lambda = 6.0）
.\ruhi-core\target\release\ruhi_eval.exe --set dev --neural-rerank ruhi_lexicon\data\rlnm_zh_tw.bin

# 5. 重排器微基準測試（涵蓋短句對比、18/24 字長句預算與 #8 跨句前文 KV 快取）
.\ruhi-core\target\release\ruhi_reranker.exe --model ruhi_lexicon\data\rlnm_zh_tw.bin --bench --threads 8
```

## 三、Stage D1–D3 技術消融、超參數校準與實境六句修復實證

1. **Stage D1（跨句前文 KV 快取 ＋ 零 IPC 變更七特徵融合）**：
   - 透過 [`ScopedContextPrefix`](file:///c:/ATGprjs/ruhi/ruhi-core/src/router/neural_reranker.rs) 傳遞最近最多 `48` 字已送出前文，並於 [`RlnmKvCache`](file:///c:/ATGprjs/ruhi/ruhi-core/src/router/rlnm.rs) 快取已計算前綴之 KV 投影，於換行／標點重置；搭配 5 折交叉驗證（5-Fold OOF CV）校準之 [`structural_fusion_bonus`](file:///c:/ATGprjs/ruhi/ruhi-core/src/router/neural_reranker.rs)（`word_count`、`single_char_count`、`ln1p(min_w)`、`ln1p(avg_w)`、`discourse_delta`），在不變動任何 COM ABI 與 Named Pipe 封包欄位前提下將 OOF CER 由 `2.89%` 降至 `2.83%`。
2. **Stage D2（前後向多樣化繞道注入 ＋ 不相交多島重組）**：
   - 於 [`viterbi.rs`](file:///c:/ATGprjs/ruhi/ruhi-core/src/router/viterbi.rs) 實作 $O(E)$ 反向動態規劃逐字位繞道（`extract_diverse_nbest_from_trellis`），消除單一歧義字位過度佔滿 Top-16/32 的餓死效應，使 `dev.tsv` 多樣化 N-Best Oracle CER 降至 **`0.93%`（`417` 錯字、整句命中率 `91.35% = 3,325 / 3,640`）**；再經 `try_build_disjoint_multi_island_recombination` 對不重疊局部島嶼進行並聯重組合成與二次打分，將端到端 `dev.tsv` CER 推進至 `2.73%`（`1,225` 錯字）。
3. **Stage D3（重訓實驗與先驗錨定解除對照）**：
   - 於本機 `NVIDIA GeForce RTX 5070 Ti`（CUDA 12.8、BF16）隔離環境進行兩組 `RLNM0001` 重訓實驗（收集 `98,953,145` 清潔字元、預訓練 `24,000` 步收斂至 `val_packed_loss = 2.7998 / packed_ppl = 16.44`，並對同音混淆句執行 `+3,000` 步對比排序微調）。由於串流階段 `traditional_chinese_odc` 與 `tw_chinese_chat` 回傳錯誤，D3 預訓練最佳點（`@ lambda = 4.5`）為 `2.65%`（`1,190` 錯字）、D3 對比微調（`@ 2.25`）為 `2.84%`（`1,272` 錯字）。
   - 相對地，解除原先校準腳本之 `lambda = 2.25` 先驗錨定後，以既有 C5 模型（`103,159,629` 清潔字元訓練，`corpus_fingerprint = 0x6f6ff534ce904c9b`，SHA-256 `0E4F45D99D8422949D3FB0A89CD4EF28A4D37675220EBF151D90337DC40B033F`）執行 `lambda` 掃描：`3.5 -> 2.65% (1,187)`、`4.5 -> 2.63% (1,180)`、`5.5 -> 2.61% (1,171)`、**`6.0 -> 2.60% (1,168, exact=2,902 / 79.73%)`**、`6.5 -> 2.62% (1,173)`、`7.0 -> 2.62% (1,176)`；五類文體全數優於 D3 模型，故實證定案保留 C5 模型並將系統預設混合權重調整為 **`lambda = 6.0`**。
4. **實境六句同音詞條與有界構式修復（`2e18c85`）**：
